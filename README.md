# TemplateGuards

**Template Guard for transition of PACS systems which may not allow templates.**

Built by Dr. Kavan R. Thompson (PGY-3 Diagnostic Radiology Resident).

## Purpose
Helps radiologists and residents maintain efficient structured reporting even when native PACS/RIS templates are restricted or unavailable. Supports seamless workflow during system transitions (common in multi-hospital HCA environments).

## Status
Early prototype. Components for dashboard preview, template uploader, and phrase converter. Supabase backend schema present.

## Live Demo
https://template-guards.vercel.app
